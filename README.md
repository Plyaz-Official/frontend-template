# My Next.js App Template

This is a starter template for a Next.js frontend app using TypeScript.

## Features

- Next.js standard structure with TypeScript
- Vercel integration with `vercel.json`
- CI/CD GitHub Actions workflow template

## Setup

1. Install dependencies:

```bash
npm install
```

## Dependency Updates

Dependencies can become outdated over time. To keep your project up to date and secure, regularly check for available updates:

```bash
npm outdated
npm update
